# Go-to-Market — Bandersnatch

This directory contains the Bandersnatch team's growth strategy, unit economics, and defensibility analysis for the Bus #3 Real-Time Tracker.

## Files

| File | Description |
|------|-------------|
| `growth-strategy.md` | Three acquisition channels ranked with activation metric, cost, reach, and open questions |
| `loops-and-moats.md` | K-factor analysis, network effects, defensibility assessment, and riskiest assumption |
| `financials/unit-economics.md` | CAC per channel, LTV projection, LTV:CAC ratio, payback period, sensitivity, and refinement schedule |
| `financials/growth-projection.xlsx` | Six-month growth projection with best/expected/worst scenarios |
| `financials/12-month-model.xlsx` | Twelve-month financial model (Combined Checkpoint 2+3) |

## Reference

The `worked-example/` subdirectory contains a completed growth strategy from the fictional StudySpace Finders team. Use it to compare structure and level of justification.
